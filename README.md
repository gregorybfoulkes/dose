# Greg

A quiet personal site for writing, built with [Zola](https://www.getzola.org/).

## Local development

Install Zola, then run:

```sh
zola serve
```

Zola serves the site locally and rebuilds it when content or templates change.
Write articles as Markdown files in `content/`.

The site's colors, typography, and layout are defined in `sass/style.scss`.
Author details and optional contact links are configured in `config.toml`.
